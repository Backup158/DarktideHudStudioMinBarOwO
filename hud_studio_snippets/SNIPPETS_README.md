# HUD Studio Snippets
These are bits of code that you cannot import as a block. These are meant to be copied and pasted into various locations, for simple reuse.

## Set Stimm Color Based on RecolorStimms
`stimm_color_RecolorStimms.lua`

In Rectangle Style --> Color --> Code --> Open the IDE then copy and paste this snippet inside. It will set the color based on the currently equipped stimm, using the option set in [RecolorStimms](https://www.nexusmods.com/warhammer40kdarktide/mods/267) if that is installed. It defaults to vanilla stimm colors otherwises.
